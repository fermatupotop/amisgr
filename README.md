# Astra Child — АМИС Групп

Каркас дочерней темы для amisgr.ru. Содержит шаблон главной страницы,
карточку товара, выборки WooCommerce и частотную шкалу.

---

## Установка

1. Заархивируйте папку `astra-amis-child` в zip.
2. Внешний вид → Темы → Добавить → Загрузить тему → активируйте.
3. Убедитесь, что родительская Astra тоже установлена (активировать её не нужно).
4. Создайте страницу «Главная», в панели справа выберите **Шаблон → Главная АМИС**.
5. Настройки → Чтение → «На главной странице отображать: статическую страницу» → выберите её.

После активации дочерней темы настройки Astra (цвета, шрифты, хедер) сохраняются —
они лежат в базе, а не в файлах темы.

## Что настроить в админке

### Шаг 1. Цвета
Настройки Astra → Глобальные → Цвета:
`Color 1 = #D9673C`, `Color 2 = #53565A`.
Тогда кнопки и ссылки WooCommerce окрасятся сами.

### Шаг 2. Атрибуты товаров
Товары → Атрибуты. Создайте с включёнными архивами:

| Название | Слаг | Для чего |
|---|---|---|
| Диапазон частот | `frequency-range` | частотная шкала в hero, фильтр каталога |
| Полоса пропускания | `bandwidth` | таблица, карточка |
| Каналы | `channels` | таблица, карточка |
| Дискретизация | `sample-rate` | таблица, карточка |
| Память | `memory` | таблица |

### Шаг 3. Термины диапазонов
В атрибуте «Диапазон частот» заведите шесть терминов.
**Название** — подпись на шкале, **описание** — пояснение под ней:

- `DC – 1 МГц` → Питание и метрология
- `1 – 200 МГц` → Схемотехника, отладка
- `200 МГц – 3 ГГц` → Связь, IoT, ЭМС
- `3 – 8 ГГц` → Wi-Fi, радиолокация
- `8 – 26,5 ГГц` → СВЧ-тракты, антенны
- `26,5 – 50 ГГц` → Миллиметровый диапазон

Счётчик приборов WordPress считает сам — руками ничего вбивать не нужно.

### Шаг 4. Сортировка по полосе
Полоса «1 ГГц» и «70 МГц» — это текст, и по нему нельзя сортировать
(«1 ГГц» окажется раньше). Поэтому у каждого осциллографа заведите
произвольное поле и впишите полосу числом в мегагерцах: `70`, `100`,
`350`, `1000`, `4000`.

Блок «Произвольные поля» — это не вкладка «Дополнительно» в данных
товара, а отдельный блок WordPress, обычно ниже редактора описания.
Если не видно: в классическом редакторе — «Настройки экрана» (правый
верхний угол) → включить «Произвольные поля»; в блочном редакторе —
меню (⋮) → «Настройки» → «Панели» → включить «Произвольные поля»
(страница перезагрузится).

Имя поля: `amis_bandwidth_mhz` — без подчёркивания в начале. Поле
с подчёркивания WordPress считает служебным и прячет из этого блока
после сохранения, найти и отредактировать его потом будет неудобно.

### Шаг 5. Форма
Поставьте Contact Form 7, создайте форму «Запрос КП», подставьте её ID
в `templates/template-home.php` (ищите `contact-form-7 id="123"`).

### Шаг 6. Параметры в карточках категорий
Пары «параметр — значение» хранятся в мете термина `amis_spec_label`
и `amis_spec_value` (несколько значений через `|`). Пока их можно
проставить любым плагином вроде Term Meta, позже — своим хуком
`product_cat_edit_form_fields`. Это хорошее первое самостоятельное задание.

## Структура файлов

```
astra-amis-child/
├── style.css                      Шапка темы + переменные бренда
├── functions.php                  Подключение стилей, хуки Astra
├── inc/
│   ├── queries.php                Все обращения к базе
│   └── shortcodes.php             [amis_freq_axis]
├── templates/
│   └── template-home.php          Шаблон главной
├── template-parts/
│   └── product-card.php           Карточка товара
└── assets/
    ├── css/home.css               Стили главной (грузятся только на ней)
    └── js/home.js                 Логика частотной шкалы
```

## Принципы, которые здесь заложены

**Стили грузятся адресно.** `home.css` подключается только на шаблоне главной —
проверка через `is_page_template()` в `functions.php`. На остальных 500 страницах
эти 17 КБ не тратятся.

**Запросы отделены от вёрстки.** Всё, что ходит в базу, лежит в `inc/queries.php`.
Шаблон только выводит. Когда понадобится поменять условие отбора — правите одну функцию.

**Вывод экранируется всегда.** `esc_html()` для текста, `esc_url()` для ссылок,
`esc_attr()` для атрибутов, `wp_kses_post()` там, где нужен HTML.
Исключения помечены комментарием, почему они безопасны.

**Никаких правок родительской темы.** Всё поведение Astra меняется хуками:
`astra_page_layout`, `astra_the_title_enabled`. При обновлении Astra ничего не слетит.

## Куда двигаться дальше

Порядок, в котором эти вещи логично осваивать на этом же проекте:

1. **Шаблон категории.** Скопируйте `archive-product.php` из
   `wp-content/plugins/woocommerce/templates/` в папку `woocommerce/` вашей темы.
   WooCommerce автоматически подхватит переопределение.
2. **Хуки вместо копирования шаблонов.** Многое в Woo меняется через
   `woocommerce_before_shop_loop_item` и соседние экшены — это чище, чем
   копировать файл целиком. Полный список: `WooCommerce → Статус → Шаблоны`
   покажет, какие ваши копии устарели после обновления плагина.
3. **Transients.** Таблица осциллографов делает запрос на каждой загрузке главной.
   Оберните результат в `set_transient()` на час — увидите разницу в Query Monitor.
4. **Query Monitor.** Поставьте этот плагин на деве прямо сейчас. Он показывает
   каждый SQL-запрос, время выполнения и какой хук что вызвал.
5. **ACF.** Когда захотите править hero-тексты из админки, а не в коде.
6. **WPCS.** Стандарты кода WordPress через PHP_CodeSniffer — приучают
   к экранированию и единому оформлению автоматически.

Локально удобно поднимать через LocalWP или Docker — правки в теме
видны сразу, без FTP.
