# АМИС ГРУПП — дочерняя тема Astra

Сайт amisgr.ru: ООО «АМИС ГРУПП», поставщик радиоизмерительного оборудования
(RIGOL, Siglent, Keysight, Tektronix, АКИП, ПриСТ). Дочерняя тема Astra,
WooCommerce, без ACF/Elementor — страницы пишутся вручную на PHP.
Подробности установки и настройки атрибутов — в `README.md`.

## Конвенции, которые нужно соблюдать

**Как делать новую страницу — два способа, оба уже используются:**
- `page-{slug}.php` — WordPress находит по адресу страницы сам, без выбора
  в админке. Годится только для страниц с зафиксированным навсегда адресом
  (`page-contact.php`, `page-payment.php`, `page-documents.php` — их URL уже
  зашит в хедере/футере).
- `templates/template-*.php` с `Template Name:` в шапке файла — привязка
  через явный выбор шаблона в редакторе страницы, не ломается при смене slug.
  **Это предпочтительный способ для новых страниц**, если нет причины жёстко
  привязываться к URL. Так сделаны `template-home.php` и `template-about.php`.

**Экранирование вывода всегда**: `esc_html()`, `esc_url()`, `esc_attr()`,
`wp_kses_post()` для HTML. Если экранирование пропущено — рядом комментарий,
почему это безопасно (например, захардкоженный SVG-путь, не пользовательский ввод).

**Данные компании — только из `inc/company.php`**: реквизиты
(`amis_company_details()`), менеджеры (`amis_company_managers()`), телефоны
(`amis_company_phones()`, `amis_phone_link()`), почта (`amis_company_email()`).
Не дублировать эти значения текстом в шаблонах.

**Стили грузятся адресно** (`functions.php` → `amis_enqueue_assets`):
`base.css` — везде, `page.css` — на всех обычных страницах кроме главной,
`home.css` — только на `template-home.php`, `product.css` — только на карточке товара.
Новый CSS для очередной обычной страницы дописывается в `assets/css/page.css`,
а не в новый файл — так уже работают контакты, доставка/оплата и «О компании».

## Грабли с Astra, на которые уже наступали

**Новый `templates/template-*.php` обязательно нужно завести в
`amis_page_builder_layout()` (`inc/enqueue.php`, не в functions.php — этот
блок туда вынесен)**, иначе Astra оборачивает страницу в свой контейнер и
добавляет собственные отступы поверх наших — итог непредсказуемый
(например, «пропадающий» отступ у секции). Сейчас это сделано универсально:
любой шаблон, у которого slug начинается с `templates/template-`, получает
`page-builder` автоматически. Для `page-contact.php`, `page-payment.php` и
`page-documents.php` — то же самое, но по имени файла, явными строками
(у них нет общего префикса, как у `templates/*`).

**Заголовки (`h1`–`h4`) нельзя красить только на родителе.** Если задать
`color` на секции и рассчитывать, что `<h1>` внутри унаследует его —
не сработает: у Astra почти наверняка есть собственное правило вида
`h1{color:...}`, а любое ПРЯМОЕ правило на элементе побеждает
унаследованное значение независимо от специфичности. Красить нужно
явно через селектор, доходящий до самого заголовка
(`.section--dark h1{color:#fff}`), не полагаясь на наследование.

**У `<a>`-кнопок на `:hover` всегда указывать `color` явно, даже если он не
меняется.** У Astra есть глобальное `a:hover{color:...}`, которое по
специфичности перебивает наш класс кнопки именно в момент ховера (у Astra
`a:hover` весит как класс+элемент, у нас часто был просто класс). Из-за
этого белый текст на кнопке на ховере откатывался к тёмному цвету ссылок
Astra. Уже поправлено для `.btn-primary`, `.btn-dark`, `.btn-ghost`,
`.catbtn`, `.buy` — если добавляете новую кнопку-ссылку с hover-эффектом,
сразу пишите `color` в правиле `:hover`, не полагайтесь на наследование
от базового класса. На `<button>` эта проблема не распространяется —
Astra цепляется только за `a`.

**Центрирование иконок в `.c-ico` — через `position:absolute` + `transform`,
не через `display:grid/flex`.** Тоже по вине Astra: где-то в её стилях
`display` на дочерних элементах контента переопределяется, и
`place-items:center`/`align-items:center` просто переставали работать.
`position:relative` на родителе почти никогда не трогается чужим CSS,
поэтому центрирование через абсолютное позиционирование надёжнее.

`stroke="currentColor"`, без иконочного шрифта.

## Уведомление о cookie

- Разметка в `footer.php` (выводится на всех страницах), стили и логика
  показа — в `base.css`/`base.js`. Показывается один раз, пока в
  `localStorage` нет отметки `amis_cookie_ack`; по нажатию «Понятно» больше
  не появляется на этом устройстве.
- Юридически необязателен для РФ (152-ФЗ не требует cookie-consent как
  GDPR) — добавлен как жест доверия. Если появится рекламный трекинг с
  передачей данных третьим лицам или сайт станет обслуживать посетителей
  из ЕС — баннер нужно переделать под явный opt-in.
